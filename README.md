## 📚 แผนการสอน 18 สัปดาห์ครบในเกมเดียว (4 โซน • 17 อาคาร • 16 ตู้เซิร์ฟเวอร์)

### โซน 1 (NW): เขตหมู่บ้านพื้นฐาน (สัปดาห์ที่ 1–5)
1. **สัปดาห์ที่ 1**: พื้นฐานระบบเครือข่ายและ NOS (Client-Server vs Peer-to-Peer, Open Source vs Proprietary) — *ศาลาลานหมู่บ้าน*
2. **สัปดาห์ที่ 2**: ระบบจำลองเครื่องคอมพิวเตอร์ (Virtualization: VirtualBox/VMware, NAT/Bridged/Internal) — *โรงหลอม VM*
3. **สัปดาห์ที่ 3**: การติดตั้งระบบปฏิบัติการเครื่องแม่ข่าย (Ubuntu Server, OpenSSH, โครงสร้าง `/etc`, `/var`, `/`) — *โรงหลอม VM*
4. **สัปดาห์ที่ 4**: การตั้งค่า Static IP (Netplan) และคำสั่ง CLI พื้นฐาน (`ip addr`, `hostnamectl`) — *ห้องคอนโซลหลัก*
5. **สัปดาห์ที่ 5**: การจัดการผู้ใช้งาน กลุ่ม และสิทธิ์ไฟล์ (`adduser`, `usermod`, เครื่องคำนวณ `chmod` 4-2-1) — *ห้องคอนโซลหลัก*

### โซน 2 (NE): เขตบริการเครือข่าย (สัปดาห์ที่ 6–10)
6. **สัปดาห์ที่ 6**: การจัดการดิสก์ ไฟล์ระบบ และ **RAID Storage** (`lsblk`, `df -h`, `/etc/fstab`, RAID 0/1/5/10) — *โกดัง RAID*
7. **สัปดาห์ที่ 7**: การบริหารจัดการระยะไกล (SSH พอร์ต 22, RDP 3389, Webmin 10000, ไม่ใช้ Telnet 23) — *หอสื่อสาร SSH*
8. **สัปดาห์ที่ 8**: การติดตั้งและจัดการ **DHCP Server** (ลำดับ D-O-R-A, IP Pool, UDP 67/68) — *ศูนย์จ่าย IP*
9. **สัปดาห์ที่ 9**: การติดตั้งและจัดการ **DNS Server** (BIND9, A / CNAME / MX Record, พอร์ต 53, `nslookup`) — *หอคอย DNS*
10. **สัปดาห์ที่ 10**: การจัดการเซอร์วิส โปรเซส และตารางงานอัตโนมัติ (**Systemd `systemctl`**, `htop`, **Cron `0 2 * * *`**) — *หอนาฬิกา Systemd*

### โซน 3 (SW): เขตบริการแอปพลิเคชันและข้อมูล (สัปดาห์ที่ 11–14)
11. **สัปดาห์ที่ 11**: **Web Server & Database Server** (LAMP Stack: Apache2 80/443, MariaDB 3306, `/var/www/html`) — *ตลาดเว็บ & DB*
12. **สัปดาห์ที่ 12**: การให้บริการแชร์ไฟล์และทรัพยากร (**Samba** พอร์ต 445, `smb.conf`, FTP 21 vs SFTP 22) — *โกดังแชร์ไฟล์*
13. **สัปดาห์ที่ 13**: **Proxy Server & Mail Server** (**Squid Proxy** พอร์ต 3128 + ACL, **SMTP 25, IMAP 143, POP3 110**) — *สถานี Proxy & Mail*
14. **สัปดาห์ที่ 14**: **Windows Server 2022** (**Active Directory AD DS**, OU/GPO, Join Domain, **IIS `C:\inetpub\wwwroot`**, **PowerShell**) — *ศาลา Windows Server*

### โซน 4 (SE): เขตความมั่นคงและการดูแลระบบ (สัปดาห์ที่ 15–18)
15. **สัปดาห์ที่ 15**: ความปลอดภัยเครื่องแม่ข่ายและไฟร์วอลล์ (**UFW Default Deny**, Port Filtering, SSH Hardening) — *ป้อมไฟร์วอลล์*
16. **สัปดาห์ที่ 16**: การสำรองและกู้คืนข้อมูล (**กฎ 3-2-1 Backup**, Full/Incremental/Differential, `tar`, `rsync`, `mysqldump`) — *คลัง Backup*
17. **สัปดาห์ที่ 17**: การเฝ้าระวังระบบ ตรวจสอบ Log และแก้ปัญหา (`/var/log/auth.log`, `journalctl`, `ss -tulnp`, วินิจฉัย 3 เคสเสียจริง) — *หอตรวจ Log*
18. **สัปดาห์ที่ 18**: โครงงานบูรณาการและประเมินระบบครบวงจร (**Final Enterprise Server Audit** + **Master Quiz 18 ข้อ** + **เกียรติบัตรพิมพ์ PDF**) — *สภาแอดมินหลวง*

## 👥 ระบบเล่นพร้อมกันกับเพื่อน (Multiplayer ทั้งแบบออนไลน์ & LAN ห้องแล็บ)
กดปุ่ม **👥 เพื่อน/ครู** (หรือกดคีย์ลัด **`L`**) เพื่อเปิดศูนย์ Multiplayer ซึ่งรองรับครบทั้ง 2 รูปแบบ:

### 1. แบบสร้างห้องด้วยรหัสห้องออนไลน์ (Room Code — ไม่ต้องลงเซิร์ฟเวอร์)
- ผู้เล่นหรือครู 1 คนกด **🏠 สร้างห้องออนไลน์ (Host)** → จะได้รหัสห้อง เช่น `SV4821`
- เพื่อน ๆ เปิด `index.html` แล้วกรอกรหัสห้องนั้นกด **🚪 เข้าร่วมห้อง** → เห็นตัวละครเพื่อนเดินในหมู่บ้าน 16-bit เดียวกัน, เห็นจุดสีฟ้าบนแผนที่ (`M`), แชทพูดคุยพร้อมบอลลูนข้อความบนหัว และส่งอีโมติคอนได้ทันที!
- *ทิปทดสอบคนเดียวบนคอมเครื่องเดียว:* เปิด `index.html` 2 แท็บ แล้วพิมพ์รหัส **`LOCAL`** เพื่อทดสอบเล่น 2 ตัวละครพร้อมกันได้ทันทีแม้ไม่มีอินเทอร์เน็ต!

### 2. แบบ LAN Server ในห้องแล็บ (ไม่ใช้อินเทอร์เน็ต 100%)
- **บน Windows (ไม่ต้องติดตั้งโปรแกรมเพิ่ม!)**: เครื่องครูดับเบิลคลิกไฟล์ **`start-lan-server.bat`** (ใช้ PowerShell ที่มีมากับ Windows) หน้าจอจะแสดง IP วง LAN เช่น `http://192.168.1.10:8080`
- **บน Linux / Ubuntu Server / macOS**: รันคำสั่ง `python3 lan-server/server.py 8080` (ใช้เฉพาะไลบรารีมาตรฐาน Python 3)
- ให้นักเรียนทุกคนเปิดเบราว์เซอร์เข้า URL ของเครื่องครู แล้วกดปุ่ม **👥 เพื่อน/ครู → เชื่อมต่อ LAN Server ห้องแล็บ**!
